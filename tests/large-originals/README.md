# Передача крупных оригиналов

Веб и нативное приложение сохраняют исходный формат одиночного объекта, пока зашифрованный файл вместе с заголовком помещается в 16 МиБ. Более крупные оригиналы до 128 МиБ включительно передаются неизменяемыми зашифрованными частями по 4 МиБ. MIME, размер, контрольная сумма и непрозрачный идентификатор набора частей находятся внутри зашифрованного дескриптора. Дескриптор и ссылка в карточке публикуются после завершения всех частей. Действующие правила доступа облака распространяются на каждую часть.

При повторе отправитель запрашивает ранее загруженные части и проверяет соответствие байтов. Web и iOS сохраняют полученный шифротекст незавершённой загрузки локально. При продолжении они проверяют подлинность каждой части и SHA-256 всего оригинала. Очистка системного кэша или нехватка локальной квоты может потребовать повторной загрузки. Если устройство окончательно прекратит отправку, уже переданные шифрованные части останутся на сервере.

Для файлов свыше 128 МиБ между устройствами передаются карточка и отметка о локальном оригинале. Исходное устройство сохраняет оригинал. Владелец другого устройства без оригинала видит ограничение, независимые записи продолжают синхронизацию. Администратор может собрать полную копию только на устройстве, где доступны все оригиналы. Старые клиенты читают файлы в прежнем формате, для крупных оригиналов на всех читающих устройствах требуется версия с поддержкой частей.

## Наблюдения

Локальный прогон использует SQLite-реле, настольный Chrome, мобильный WebKit и системные Swift/CryptoKit в iOS Simulator. Устройства и данные синтетические.

| Размер ZIP | Проверка |
|---|---|
| 4096 байт | Нативная запись, чтение нативным клиентом и Chrome. SHA-256 совпал |
| 16 777 170 байт | Последний ZIP с MIME application/zip в старом формате. Проверенный размер шифротекста 16 777 216 байт |
| 16 777 171 байт | Первый ZIP этого MIME в новом формате. Сохранились отдельные части и 206-байтовый зашифрованный дескриптор. SHA-256 совпал |
| 17 826 043 байта | Загрузили в визит через Chrome. При выключении сети в середине публикации карточка вложения оставалась локальной. После перезагрузки повтор использовал ранее отправленную часть. На Mobile WebKit прервали скачивание, перезагрузили страницу, сохранили эпизод и открыли оригинал без сети. После экспорта и восстановления семейного .health SHA-256 совпал. Этот же оригинал прочитан нативным кодом симулятора |
| 134 217 728 байт | Нативный симулятор записал ZIP, проверил чтение, Chrome загрузил его и поместил в локальное зашифрованное хранилище. SHA-256 совпал |
| 134 217 729 байт | Оригинал с устройства автора сохранился локально. Другие устройства получили карточку с ограничением и независимое изменение поля профиля. Администратор без оригинала увидел отказ в создании неполной копии |

Отдельный прогон через **действующее Cloudflare-реле** передал один ZIP 17 826 043 байта из Chrome в отдельный профиль мобильного WebKit пятью шифрованными частями. Отправитель использовал рабочий клиент, загруженный под разрешённым origin GitHub Pages. Реле обработало реальные сетевые запросы. Копия .health открылась в чистом контексте, совпал SHA-256 `15e3eefc846dfd9d382a7f6924c20235c6a7f68d8997ef1c0fc6a72fb607742a`. Тариф и параметры облака не менялись. Стресс-проверки верхней границы выполнялись локально.

## Воспроизведение

Нужны установленный модуль playwright-core, Chrome, совместимый WebKit и для межплатформенной проверки Xcode с уже запущенным симулятором. Подготовьте временную директорию и локальное реле.

```sh
export HS_LARGE_SCRATCH="$(mktemp -d)"
python3 tests/large-originals/fixtures.py "$HS_LARGE_SCRATCH/files"
python3 serve_preview.py --port 18257 --sync-store "$HS_LARGE_SCRATCH/sync.sqlite"
```

Во второй консоли укажите тот же каталог и запустите проверку. Скрипт использует только временные профили браузеров. Для браузерной проверки достаточно последней команды.

```sh
export HS_NATIVE_LARGE_CHECK="$HS_LARGE_SCRATCH/native"
xcrun --sdk iphonesimulator swiftc -target arm64-apple-ios17.0-simulator \
  -sdk "$(xcrun --sdk iphonesimulator --show-sdk-path)" \
  ios/HealthStory/DeviceSecurity.swift ios/HealthStory/DeviceExchange.swift ios/HealthStory/DeviceSyncRules.swift \
  tests/large-originals/ExchangeCheck.swift -o "$HS_NATIVE_LARGE_CHECK"
node tests/large-originals/ui.cjs
```

Если используется несколько симуляторов, задайте `HS_SIMULATOR_ID`. Проверка через действующий облачный сервис запускается отдельно флагом `--cloud`; она требует `HS_SETUP_FILE` с кодом создания учебной семьи и расходует квоту облачного хранилища.
