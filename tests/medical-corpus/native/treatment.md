# Нативные курсы лечения и сводка по эпизоду

В профиле iPhone наверху показаны активные курсы и три последних визита. Полный список открывается через «Все визиты». В карточке визита доступны исходная схема, статус курса, прежние решения врачей, рекомендации и общие пометки. Из визита открывается сводка именно по его эпизоду. При входе из профиля с несколькими эпизодами их можно выбрать.

При редактировании изменяется период в том же месте, из которого веб-приложение читает назначение: в ручном визите, в сверенном файле назначений или в замене, сохранённой врачебным решением. Название, форма, дозировка и схема остаются в карте врача. Неизвестный день окончания хранится отдельным признаком. Общая дата завершает только остающиеся открытыми назначения выбранного визита.

## Повторение проверки

Для теста нужен загруженный симулятор iOS и Xcode. Передайте UUID симулятора, указанный командой `xcrun simctl list devices booted`. Проверка устанавливает отдельную сборку с идентификатором by.healthstory.treatmentui. Используются исключительно синтетическая семья и тестовый ключ.

```sh
python3 tests/medical-corpus/native/ui-check.py SIMULATOR_UUID --case treatment
```

[XCTest](TreatmentUI.swift) открывает зашифрованное семейное хранилище, сверяет активные курсы, изменяет период из файла, завершает группу назначений, выбирает неизвестную дату для препарата-замены и сохраняет общую пометку. Из исходного визита тест открывает сводку и проверяет изоляцию другого эпизода. Затем [проверка архива](treatment_fixture.py) читает сохранённый iOS-файл, проверяет автора, фактические даты, признак неизвестной даты и исходное назначение. Ключ этого стенда неприменим к личным архивам.
