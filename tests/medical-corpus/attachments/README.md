# Вложения исследования QA-XR-07

Все пять файлов созданы для теста. Объект исследования — цифровой рентгеновский фантом с кольцом, тремя круглыми вставками, семью ступенями плотности и четырьмя группами полос. Проекция вычислена из геометрической модели с воспроизводимым шумом. Все подписи относятся к вымышленному стенду.

## Ручная проверка

Откройте учебный визит, нажмите «Прикрепить файл» и выберите одновременно все оригиналы из папки [files](files). В выпадающем списке «Файл для предпросмотра» последовательно переключите документы. Укажите категории по таблице и сохраните визит.

| Файл | Категория | Что должно быть видно |
|---|---|---|
| [PNG](files/01-phantom.png) | Снимки | Монохромная проекция 640 × 640, надпись QA-XR-07 |
| [JPEG](files/02-phantom-photo.jpg) | Снимки | Та же проекция после сжатия |
| [Заключение PDF](files/03-phantom-report.pdf) | Заключения | Первая страница содержит текст заключения. На второй странице — отдельная контрольная проекция |
| [Записка TXT](files/04-technician-note.txt) | Другое | Кириллица, номер исследования, знаки × и №, переносы строк CRLF |
| [DICOM в ZIP](files/05-phantom-dicom.zip) | Снимки | Подсказка о внешнем просмотрщике и скачивание оригинала. В архиве один файл QA-XR-07/IM000001.dcm |

В готовой карточке откройте вложения повторно и скачайте оригиналы. Файл [expected.json](expected.json) содержит категории, SHA-256, размеры и ожидаемые типы предпросмотра. DICOM прочитан с помощью pydicom 3.0.1. Он содержит монохромный 8-битный кадр Secondary Capture, Explicit VR Little Endian. Значения всех 409 600 пикселей совпали с PNG.

## Результаты браузерной проверки

26 ноября 2026 года [verify.cjs](verify.cjs) прошёл в локальном приложении для трёх вариантов переноса.

| Создание зашифрованной копии | Восстановление в чистом контексте | Результат |
|---|---|---|
| Chrome на компьютере | Chrome на компьютере | 5 из 5 совпадений SHA-256 |
| WebKit, эмуляция iPhone 13 | WebKit, эмуляция iPhone 13 | 5 из 5 совпадений SHA-256 |
| Chrome на компьютере | WebKit, эмуляция iPhone 13 | 5 из 5 совпадений SHA-256 |

В каждом прогоне семья и визит созданы через интерфейс. Для PNG и JPEG проверено декодирование изображения, для PDF — отрисовка двух разных страниц, для TXT — контрольная строка, для ZIP — переход к скачиванию. Проверены пакетная загрузка, связь каждого файла с визитом, название файла при скачивании и контрольные суммы до и после переноса. Пустой TXT отклонён. ZIP в категории «Лаборатория» отклонён вместе со всей пачкой. Исходный визит после отказа остался без вложений. Проверки прошли без внешних HTTP-запросов.

[Снимок восстановленного PDF в Chrome](evidence/chrome-restored-report.webp) · [Снимок в мобильном WebKit](evidence/webkit-restored-report.webp).

Для повтора запустите локально `python3 serve_preview.py`, затем следующие команды с доступным модулем `playwright-core`, установленным Chrome и соответствующей версией WebKit.

```sh
node tests/medical-corpus/attachments/verify.cjs
node tests/medical-corpus/attachments/verify.cjs --iphone
node tests/medical-corpus/attachments/verify.cjs --to-iphone
```

Переменная `HEALTH_PREVIEW_URL` позволяет выбрать адрес локального стенда. Переменная `HEALTH_EVIDENCE_DIR` задаёт каталог для снимка восстановленного PDF. Проверка ограничена веб-приложением. Физический iPhone и нативный просмотрщик DICOM в этих трёх прогонах не участвовали.
