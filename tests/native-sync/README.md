# Нативный обмен, расхождения и офлайн-оригиналы

Проверки создают изолированную семью и синтетические ключи на локальном сервере. На симуляторе устанавливается отдельное тестовое приложение. Рабочий семейный архив для этих тестов не нужен.

Из корня репозитория на macOS с Xcode запустите локальный сервер в отдельном терминале.

```sh
scratch=$(mktemp -d)
python3 serve_preview.py --port 18257 --sync-store "$scratch/sync.sqlite"
```

В другом терминале проверьте код объединения, права и отзыв устройства.

```sh
scratch=$(mktemp -d)
xcrun swiftc ios/HealthStory/{DeviceSecurity,DeviceReconnection,DeviceSyncRules,DeviceExchange}.swift tests/native-sync/Verify.swift -o "$scratch/verify"
"$scratch/verify" http://127.0.0.1:18257/ assets/app/sync-merge.js
```

Проверка создаёт конкурирующие изменения одного поля, сверяет автора и время создания локальной правки, проверяет права ребёнка и взрослого на разрешение конфликта и изменение настроек отправки в ИИ. Отдельное разрешение ChatGPT доходит до детской карты, сохраняется при изменении OpenRouter и снимается после отзыва в вебе. Если значение изменилось после выбора, следующий обмен возвращает новые альтернативы. Отдельный сценарий проверяет отбор вложений эпизода, сохранение локального оригинала после отзыва доступа и отказ сервера выдать обновлённый список профилей и новый оригинал.

Для проверки интерфейса загрузите отдельный симулятор iPhone, подставьте его UUID вместо `SIMULATOR_UUID` и выполните в том же терминале.

```sh
"$scratch/verify" http://127.0.0.1:18257/ assets/app/sync-merge.js "$scratch/synthetic-grant.json"
python3 tests/medical-corpus/native/ui-check.py SIMULATOR_UUID --case sync --sync-fixture "$scratch/synthetic-grant.json" --sync-relay http://127.0.0.1:18257/
```

XCUITest выбирает карточку ребёнка от лица взрослого, разрешает расхождение и загружает два оригинала эпизода. После перезапуска с недоступным адресом тест открывает заключение из защищённого хранилища. Путь к журналам сборки и результату Xcode выводится в начале запуска. Для повтора создайте новую синтетическую семью командой `verify` с путём к файлу. Файл содержит временный тестовый доступ.
